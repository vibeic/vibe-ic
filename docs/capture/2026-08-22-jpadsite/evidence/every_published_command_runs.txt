writes `derives nothing` in LOWERCASE. This report rendered it `DERIVES NOTHING`.

and takes both as the flow owner's. My emphasis was misrepresenting which word
the flow owner chose to stress, inside the one quotation the report relies on to
say a precedence question is already settled. Restored; my emphasis moved to my
own prose.

The rule that saved both: a MISSING result gets verified by hand before it gets
acted on. A found result is self-checking; a missing one is not.
