## Note on TB read timing (honest)
First run readback showed all-zero on OURS only. Root cause was a **testbench**
artifact, not an OURS bug: OUR top has a *combinational* read path (read_data
valid same cycle while `cs && !we`), REF has a *registered* read path. The
initial `rd` task deasserted `cs` before sampling. The corrected `rd` task holds
`cs` high across two edges and samples both combinationally and after the clock,
so it works for both read styles → OURS then passed 20/20 identically to REF.
This is recorded transparently; no result was fabricated.
