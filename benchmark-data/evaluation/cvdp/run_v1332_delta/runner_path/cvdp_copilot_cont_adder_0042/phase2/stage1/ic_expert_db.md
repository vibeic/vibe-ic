## IC Expert DB — relevant design-class knowledge (advisory)
Proven design-craft for similar designs. Apply the algorithm / interface / latency insight; the deterministic gates still decide PASS.

- **[axi4lite-register-slave]** An AXI4-Lite slave register file must implement each channel as an independent, self-clearing handshake FSM: assert *ready only until the corresponding *valid fires (one-shot, then de-assert), latch the address into a holding register at accept time, and hold bvalid/rvalid asserted until the master's bready/rready acknowledges before dropping it — otherwise responses are lost or the bus double-fires. Decode on the LATCHED address (not the live bus), honor write-strobe semantics (full-strobe = update, partial = ack-without-modify), and always return an error response (SLVERR) for writes to read-only or undefined offsets rather than silently completing OKAY.
- **[integer-clock-divider]** Integer clock divider: divided-clock outputs described as 'toggled'/'reset-initialized' are REGISTERS, not a combinational decode of the current count. The CANONICAL odd-divisor 50%-duty divider is the OR of a posedge half-rate LEVEL and a negedge half-rate LEVEL: use one counter cnt1 on posedge and cnt2 on negedge, each counting 0..NUM_DIV-1, and register each level as `clk_div_k <= (cnt_k < NUM_DIV/2)` (a LEVEL that is high for the first floor(NUM_DIV/2) counts, NOT a single toggle-at-a-point — a lone toggle every NUM_DIV counts would divide by 2*NUM_DIV, not NUM_DIV). The reset value of each clk_div_k is DERIVED, not guessed: cnt resets to 0 and 0 < NUM_DIV/2, so the level is 1 at reset — reset clk_div_k to 1'b1 to match its own cnt==0 level. Combine with `clk_div = clk_div1 | clk_div2`. A combinational `assign clk_div=(cnt<LIMIT)` or a toggle-on-limit form shifts the phase and fails a cycle-accurate check even when the average ratio is right.
- **[apb-csr-shift-register]** When a spec says a register "updates on the rising edge of <signal>", model that signal as an actual clock (`always @(posedge signal or negedge presetn)`) rather than sampling it in the main clock domain — the checker drives that signal as a clock edge, so a synchronizer/edge-detector approach would miss updates. Correspondingly, implement glitch-free clock gating by latching the enable on the OPPOSITE (negedge) clock edge before ANDing with the clock (`gated_clk = pclk & enable_latched_on_negedge`), and give misprediction-restore strict priority over the normal LSB shift-in. For the APB CSR wrapper: register-map reads must zero-extend reserved bits, read-only registers must silently ignore writes, and pslverr must assert only on invalid addresses during a qualified (pselx && penable) access with zero wait states (pready held high).
- **[axi-mmio-cdc-datapath]** In an AXI4 memory-mapped control block driving a datapath in a second clock domain, three separations must all hold: (1) AXI writes must decouple the address phase from the data phase (latch AWADDR into a write pointer, then per-beat for INCR bursts advance the pointer by the data width, e.g. +4) rather than reusing the static AWADDR each beat; (2) every control/data signal crossing a clock boundary needs its own multi-flop synchronizer, and for a multi-bit result crossing back the readback register must sample the SYNCHRONIZED value, not the raw datapath output; and (3) address decode must gate on alignment and region (mem vs CSR) so the same write channel routes to either RAM or config registers. A naive author leaves the burst pointer static, synchronizes only single-bit controls (letting multi-bit buses skew), or lets the CPU read a value that never crossed back into the AXI domain.
- **[mac-accumulator]** For a multi-stage streaming MAC/accumulator, size the accumulator to exactly 2*DWIDTH + $clog2(N) bits (product width plus carry growth for summing N terms) and gate every pipeline register on a valid signal that has been delayed to match its own stage, so counting, accumulation, and valid_out all track the true datapath latency (first result at N+1 cycles). The critical trap: gapped valid_i must freeze all stages (hold state, advance nothing), and at the window boundary the accumulator must restart by loading the in-flight product rather than zeroing — otherwise the first sample of the next window is dropped and back-to-back windows lose one term.
