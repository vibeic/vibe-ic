Modify the RTL code `gf_mac` to include additional functionality for **error detection** and **result validation** to extend its use cases. The enhanced RTL module `gf_mac` should consider the following specifications.

---

## Error Detection

Introduce a new output signal, `error_flag`, into the design. This signal indicates whether an error has occurred during the computation:

- **Invalid Width Detection**:
  - The `error_flag` should be set to `1` when the input parameter `WIDTH` is **not** a multiple of 8.
  - This enforces the requirement that `WIDTH` must be a multiple of 8 for correct operation.
- **Valid Width**:
  - The `error_flag` should be set to `0` when `WIDTH` is a valid multiple of 8.

## Result Validation

Introduce another output signal, `valid_result`, into the design. This signal indicates whether the `result` output is valid:

- **Valid Computation**:
  - The `valid_result` should be set to `1` when the computation is successful, i.e., when `WIDTH` is a multiple of 8.
- **Invalid Computation**:
  - The `valid_result` should be set to `0` when the computation is not performed due to an invalid `WIDTH`.

## Module Behavior

The module should perform Galois Field (GF) multiplication and accumulation as before, with the following behaviors:

### When `WIDTH` Is a Multiple of 8

- **Input Segmentation**:
  - Divide the inputs `a` and `b` into 8-bit segments.
  - For `WIDTH = N`, there will be `N / 8` segments.
- **Segment-wise GF Multiplication**:
  - Multiply each corresponding pair of 8-bit segments from `a` and `b` using GF(2^8) multiplication.
  - Use an irreducible polynomial (e.g., `0x11B`) for the GF(2^8) field.
- **Result Accumulation**:
  - XOR all the multiplication results to produce a final 8-bit `result`.
- **Output Signals**:
  - Set `valid_result` to `1`.
  - Set `error_flag` to `0`.

### When `WIDTH` Is Not a Multiple of 8

- **Error Handling**:
  - Do not perform any computation.
- **Output Signals**:
  - Set `result` to `8'b0`.
  - Set `valid_result` to `0`.
  - Set `error_flag` to `1`.

## Example Computations

### Example: Invalid `WIDTH`

**Input Parameters**:

- **WIDTH**: `14` (not a multiple of 8)
- **Inputs**:
  - **a**: `14'b00100100001100` (lower 14 bits of `0x1234`)
  - **b**: `14'b10101011110011` (lower 14 bits of `0xABCD`)

**Computation Steps**:

1. **Error Detection**:
   - Since `WIDTH % 8 != 0`, set `error_flag = 1`.
   - Do not perform any computation.

2. **Output Signals**:
   - `result = 8'b00000000`
   - `valid_result = 0`
   - `error_flag = 1`
