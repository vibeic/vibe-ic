Serial-GMII (SGMII) Specification
Revision 1.8, Cisco Systems, Inc., Document Number ENG-46158

1. Introduction
The Serial Gigabit Media Independent Interface (SGMII) is a SerDes-based
interface that carries the Gigabit Media Independent Interface (GMII) signals
between an Ethernet MAC and a PHY over a single differential pair per direction.
SGMII replaces the wide 10-bit parallel GMII data path (and its companion
control and clock pins) with one serialized 1.25 Gbaud differential lane in each
direction, dramatically reducing the pin count of the MAC<->PHY connection while
carrying 10 Mbps, 100 Mbps, and 1000 Mbps Ethernet traffic transparently.
SGMII is a chip-to-chip / chip-to-module link layer; it is NOT the Ethernet MAC
frame layer (it does not define preamble/SFD, MAC addressing, or the Ethernet
frame CRC-32), and it is NOT RGMII (which is a parallel reduced-pin GMII using
4-bit DDR data buses).

2. Signal Definition
SGMII uses two differential pairs (four signals) plus optional reference clocks:
  TXP / TXN    - Transmit differential pair (MAC to PHY direction), 1.25 Gbaud.
  RXP / RXN    - Receive differential pair (PHY to MAC direction), 1.25 Gbaud.
  TXCLKP/TXCLKN- Optional 625 MHz DDR source-synchronous transmit clock pair.
  RXCLKP/RXCLKN- Optional 625 MHz DDR source-synchronous receive clock pair.
  SYNC         - Internal code-group alignment / comma-detect status (logical).
The electrical layer is LVDS or CML differential signaling. Both the TX and RX
lanes run at a fixed 1.25 GBd serial line rate regardless of the negotiated
Ethernet speed; the 625 MHz figure is the DDR clock (data on both edges). The
signaling is independent of the Ethernet operating speed because lower speeds
replicate each GMII byte rather than slowing the line rate.

3. Line Code (8B/10B)
SGMII encodes the serialized GMII octet stream with 8B/10B coding identical to
1000BASE-X (IEEE 802.3 Clause 36). Each 8-bit data octet maps to a 10-bit code
group selected to maintain DC balance through running disparity (RD+/RD-).
Special K (control) code groups delimit and align the stream:
  /K28.5/  - Comma; the code-group alignment character used for byte/word sync.
  /I/      - Idle ordered set: /I1/ and /I2/ keep the link alive between frames
             and correct running disparity.
  /C/      - Configuration ordered set carrying the 16-bit Config_Reg during
             Auto-Negotiation.
  /S/      - Start_of_Packet ordered set (replaces the first preamble octet).
  /T/      - End_of_Packet (terminate) ordered set.
  /R/      - Carrier_Extend / fill ordered set.
The receiver achieves code-group synchronization by detecting the /K28.5/ comma
and establishing 10-bit code-group boundaries, after which running disparity is
tracked continuously.

4. Auto-Negotiation and the SGMII Config_Reg
SGMII reuses the 1000BASE-X PCS Auto-Negotiation state machine (IEEE 802.3
Clause 37), exchanging /C/ ordered sets that carry a 16-bit configuration word
(tx_config_reg). For SGMII the meaning of that word is REDEFINED relative to
1000BASE-X: instead of advertising 1000BASE-X duplex/pause abilities, the PHY
encodes the resolved link state and the MAC acknowledges it. The 16-bit SGMII
Config_Reg sent by the PHY toward the MAC is:
  Bit 0     : 1 (must be set, identifies SGMII Config_Reg)
  Bits 9:1  : Reserved (0)
  Bits 11:10: Link Speed   (00 = 10 Mbps, 01 = 100 Mbps, 10 = 1000 Mbps, 11 = Reserved)
  Bit 12    : Duplex       (1 = Full duplex, 0 = Half duplex)
  Bit 13    : Reserved (0)
  Bit 14    : Acknowledge  (ACK, set by the MAC in its reply Config_Reg)
  Bit 15    : Link         (1 = link up, 0 = link down)
The PHY drives the resolved speed/duplex/link toward the MAC; the MAC echoes
the word with the Acknowledge bit (bit 14) set to complete the handshake. The
Auto-Negotiation page-exchange completes when both ends have received three
consecutive identical /C/ ordered sets (the ability_match / consistency check).

5. Speed Adaptation (rate replication)
Because the SGMII serial line is always 1.25 GBd (1000 Mbps equivalent payload),
operation at 10 Mbps and 100 Mbps is achieved by replicating each GMII data
octet on the line: each octet is repeated 100 times for 10 Mbps and 10 times
for 100 Mbps. The receiver de-replicates by sampling one of every N identical
octets. This keeps the SerDes clock, comma alignment, and 8B/10B framing fixed
across all three speeds.

6. Ordered Sets (encoding summary)
  Idle1 (/I1/)        : /K28.5/ /D5.6/   (used when running disparity is +)
  Idle2 (/I2/)        : /K28.5/ /D16.2/  (used when running disparity is -)
  Configuration (/C/) : /K28.5/ /D21.5/ + Config_Reg(low) , /K28.5/ /D2.2/ + Config_Reg(high)
  Start (/S/)         : /K27.7/          (Start_of_Packet)
  Terminate (/T/)     : /K29.7/          (End_of_Packet)
  Carrier_Extend (/R/): /K23.7/          (extend / fill)
  Error_Propagation   : /K30.7/          (/V/ invalid, error indication)

7. Transmit and Receive Data Path
On the transmit side the MAC presents GMII (8-bit GMII_TXD, GMII_TX_EN,
GMII_TX_ER, GMII_GTX_CLK). The SGMII transmit PCS converts an Ethernet packet
into: /S/ replacing the first preamble byte, the 8B/10B-encoded packet octets,
then /T/ and /R/ to close the frame, with /I/ between frames. On the receive
side the SGMII PCS recovers the clock, aligns on /K28.5/, decodes 8B/10B,
strips ordered sets, and re-presents GMII (GMII_RXD, GMII_RX_DV, GMII_RX_ER,
GMII_RX_CLK) to the MAC.

8. Registers / Configuration Word Map
The principal programmable state is the Auto-Negotiation Config_Reg pair:
  tx_config_reg[15:0]  - Config_Reg transmitted in /C/ ordered sets.
  rx_config_reg[15:0]  - Config_Reg received from the link partner.
  an_enable            - Enable Clause-37-style Auto-Negotiation.
  an_restart           - Restart the Auto-Negotiation page exchange.
An_link_status and the resolved speed/duplex are derived from rx_config_reg
once ability_match + acknowledge_match + consistency are satisfied.

9. State Machine
The Auto-Negotiation finite state machine follows Clause 37:
  AN_ENABLE      - Reset state; clear ability_match.
  AN_RESTART     - Force /C/ with Config_Reg = 0 (link_timer).
  ABILITY_DETECT - Transmit /C/ with tx_config_reg; watch rx_config_reg.
  ACKNOWLEDGE_DETECT - Set bit 14 (ACK) once 3 consecutive matching /C/ seen.
  COMPLETE_ACKNOWLEDGE - Both ends acknowledged.
  IDLE_DETECT    - Switch to /I/ idle.
  LINK_OK        - Pass GMII data; link_status = up.
A link_timer (1.6 ms nominal) bounds each Auto-Negotiation phase.

10. Timing
  Serial line rate         1.25 GBd (both TX and RX, all speeds)
  DDR clock                625 MHz (optional source-synchronous clock)
  Bit period (UI)          0.8 ns
  Code group               10 bits (8B/10B), 8 ns per code group
  Octet replication        x100 at 10 Mbps, x10 at 100 Mbps, x1 at 1000 Mbps
  link_timer               1.6 ms (Auto-Negotiation phase bound)
  Comma alignment          on /K28.5/ detection

11. Comparison and Scope (what SGMII is NOT)
SGMII is the MAC<->PHY SerDes link. It does not implement the Ethernet MAC frame
structure: there is no preamble/SFD field definition, no 48-bit MAC source/
destination address, and no Ethernet FCS/CRC-32 framing inside this spec — those
belong to the MAC layer above. SGMII also differs from RGMII: RGMII is a
parallel reduced-pin GMII using two 4-bit DDR data buses at 125 MHz, whereas
SGMII is a single serialized 1.25 GBd differential pair using 8B/10B. SGMII
differs from 1000BASE-X only in the redefinition of the Auto-Negotiation
Config_Reg (speed/duplex/link encoding instead of 1000BASE-X ability bits).

12. Compliance Summary
A compliant SGMII link:
  - Runs the serial lane at a fixed 1.25 GBd in both directions for all speeds.
  - Uses 8B/10B coding with running disparity and aligns on the /K28.5/ comma.
  - Exchanges /C/ ordered sets carrying the 16-bit SGMII Config_Reg.
  - Encodes Link Speed in Config_Reg bits 11:10, Duplex in bit 12, ACK in bit
    14, and Link in bit 15.
  - Replicates each GMII octet x100 (10 Mbps) or x10 (100 Mbps) to hold the
    line rate constant.
  - Maps the GMII transmit/receive byte stream transparently MAC<->PHY.
