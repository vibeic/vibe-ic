Interlaken Protocol Definition
Revision 1.2, Cortina Systems and Cisco Systems

1. Introduction
Interlaken is a narrow, high-speed, channelized chip-to-chip packet interface
that runs over multiple bonded SerDes lanes. It was jointly defined by Cortina
Systems and Cisco Systems as a scalable interconnect for packet processors,
traffic managers, framers, and switch fabrics. Interlaken transports packets
that are segmented into bursts; each burst is delimited by Control Words while
the packet payload travels in Data Words. The protocol layers cleanly into a
Protocol Layer (bursts, channels, flow control) running on top of a Framing
Layer (64B/67B word encoding, metaframe, lane striping, integrity), which in
turn rides on a set of bonded SerDes lanes (the PCS/PMA).

Interlaken is a SerDes framing protocol, not a local-area-network link layer.
Whereas a LAN link layer carries addressed media frames through an 8B/10B or
64B/66B physical coding sublayer, Interlaken has no addressed media frame and no
station-address scheme. Instead Interlaken uses 64B/67B word encoding, a
metaframe (Synchronization / Scrambler State / Skip / Diagnostic control words),
Burst and Idle Control Words, and channelized bursts with an in-band per-channel
flow-control calendar.

2. Word Encoding (64B/67B)
The Framing Layer encodes data on each lane using 64B/67B. Every 67-bit word
carries 64 payload bits plus 3 framing bits:
  Bit 66  Inversion bit. The 64 payload bits may be bit-inverted to bound the
          running disparity; bit 66 records whether inversion was applied.
  Bit 65  Scrambled bit. Indicates whether the payload was scrambled by the
          self-synchronous scrambler (polynomial x^58 + x^39 + 1).
  Bit 64  Control/Data type bit. 1 = Control Word (framing layer word),
          0 = Data Word (packet payload).
Words are 8 bytes (64 bits) of payload framed to 67 bits on the wire. The
64B/67B framing achieves DC balance and lane synchronization without the 25%
overhead of 8B/10B.

3. Word Types
There are two top-level word types selected by bit 64:
  Control Word (bit 64 = 1) - a framing-layer word. Control Words include the
    Burst/Idle Control Word (Protocol Layer framing) and the four metaframe
    control words (Synchronization, Scrambler State, Skip, Diagnostic).
  Data Word (bit 64 = 0) - 8 bytes of packet payload.

4. Burst Framing (Protocol Layer)
The Protocol Layer segments each packet into bursts. A burst is a run of Data
Words delimited by Control Words. The Control Word that PRECEDES a burst is the
Burst Control Word and carries the Start-Of-Packet (SOP) indication, the channel
number, and the in-band flow-control status. The Control Word that FOLLOWS a
burst is the Idle/Burst Control Word and carries the End-Of-Packet (EOP)
indication, an error bit, and the EOP_Format field (the count of valid bytes in
the final Data Word, 1 to 8). Between bursts the link inserts Idle Control Words.

Burst parameters constrain burst length:
  BurstMax    - the maximum number of payload bytes between two Control Words.
                Typical value 256 bytes.
  BurstShort  - the burst size used when a packet is shorter than BurstMin.
                Typical value 32 bytes.
  BurstMin    - the minimum payload between Control Words for a non-final burst
                (a multiple of 32, e.g. 64 bytes), so flow-control opportunities
                occur often enough.

5. Control Word Format (Burst/Idle)
The Burst/Idle Control Word (bit 64 = 1) carries:
  Control Type    Distinguishes a Burst Control Word from an Idle Control Word.
  SOP             Start-Of-Packet; set on the Control Word that starts a packet.
  EOP_Format      End-Of-Packet format; 0 = not EOP, else 1..8 = valid bytes in
                  the last Data Word.
  Error (ERR)     Marks the burst as errored (e.g. upstream abort).
  Channel Number  The logical channel this burst belongs to (up to 65536).
  Flow Control    In-band per-channel XON/XOFF status bits (the calendar).
  CRC-24          A 24-bit CRC computed over the burst and the Control Word for
                  per-burst integrity (polynomial 0x328B63).
  Reset Calendar  Bit that resets the flow-control calendar position.

6. Metaframe (Framing Layer)
The Framing Layer inserts, every MetaFrameLength words on EACH lane, a fixed
sequence of four control words that bound a metaframe. The metaframe provides
word lock, lane alignment, scrambler synchronization, clock compensation, and
per-lane diagnostics. MetaFrameLength is configurable (e.g. 2048 words). The
four metaframe control words are:
  Synchronization Word  - a fixed framing pattern 0x78f678f678f6 used to obtain
                          word boundary lock and to align (deskew) the lanes.
  Scrambler State Word  - carries the current scrambler state so a receiver can
                          synchronize its descrambler to the self-synchronous
                          scrambler (x^58 + x^39 + 1).
  Skip Word             - a repeatable word the receiver may add or delete to
                          perform clock compensation between the two ends'
                          reference clocks (rate matching / elastic buffer).
  Diagnostic Word       - carries a per-lane CRC-32 (polynomial 0x04C11DB7)
                          over the metaframe plus lane health/status bits
                          (Status: lane operational, Lane number).

7. Lane Bonding and Striping
The Protocol Layer hands a stream of 64-bit words to the Framing Layer, which
distributes (stripes) the words round-robin across the N bonded SerDes lanes.
Each lane independently 64B/67B-encodes, scrambles, and inserts its own
metaframe. The receiver word-locks each lane on the Synchronization Word,
descrambles using the Scrambler State Word, deskews the lanes using the
metaframe boundaries (and absorbs clock difference via Skip Words), then
de-stripes the words back into the original ordered word stream.

8. Scrambling
A self-synchronous scrambler with polynomial x^58 + x^39 + 1 is applied per lane
to the payload to ensure transition density and DC balance. Bit 65 marks
whether a word was scrambled. The Scrambler State Word in each metaframe lets
the receiver lock its descrambler.

9. Integrity (CRC-24 and CRC-32)
Interlaken uses two CRCs:
  CRC-24  Per-burst integrity carried in the Burst/Idle Control Word, polynomial
          0x328B63, covering the burst Data Words and the Control Word. A CRC-24
          mismatch marks the burst errored.
  CRC-32  Per-lane diagnostic integrity carried in the Diagnostic Word of each
          metaframe, polynomial 0x04C11DB7, covering the metaframe on that lane.

10. Flow Control
Interlaken carries flow control in-band: every Control Word includes a calendar
of per-channel XON/XOFF status. The calendar advances through the channels so
that, over a small number of Control Words, the XON/XOFF state of every channel
is communicated. XON (1) permits the far end to send on a channel; XOFF (0)
back-pressures it. An out-of-band flow-control interface (a separate LVDS bus
with sync, data, and clock signals) is also defined for systems that prefer to
carry flow control outside the data path.

11. Channels
Interlaken is channelized: a single physical link multiplexes many logical
channels. The Channel Number field in the Burst Control Word selects the channel
for a burst. The protocol supports up to 65536 channels (16-bit channel number),
each independently flow-controlled by the calendar.

12. Signals
An Interlaken interface consists of:
  TX_SERDES[N-1:0]   - N transmit SerDes lanes (differential).
  RX_SERDES[N-1:0]   - N receive SerDes lanes (differential).
  TXCLK / RXCLK      - per-direction reference clocks for the SerDes.
  FC_SYNC / FC_DATA / FC_CLK - optional out-of-band flow-control LVDS bus.
The number of lanes N is implementation-defined (e.g. 4, 10, 12, 24 lanes) and
each lane runs at the SerDes line rate (e.g. 6.25, 10.3125, 12.5 Gbps).

13. Reset and Alignment
On reset the receiver searches each lane for the Synchronization Word to obtain
word lock, then uses successive metaframe boundaries to deskew the bonded lanes
into alignment. The link is considered up when all lanes are word-locked,
descrambler-synchronized, deskewed, and the Diagnostic Word reports lanes
operational.

14. Parameters and Constants
  WORD_PAYLOAD_BITS   64
  WORD_WIRE_BITS      67 (64B/67B)
  CTRL_TYPE_BIT       bit 64 (1 = Control Word, 0 = Data Word)
  SCRAMBLED_BIT       bit 65
  INVERSION_BIT       bit 66
  CHANNEL_NUMBER_BITS 16 (up to 65536 channels)
  CRC24_POLY          0x328B63
  CRC32_POLY          0x04C11DB7
  SCRAMBLER_POLY      x^58 + x^39 + 1
  SYNC_WORD           0x78f678f678f6
  METAFRAME_LENGTH    2048 words (configurable)
  BURST_MAX           256 bytes (typical)
  BURST_SHORT         32 bytes (typical)
  BURST_MIN           64 bytes (multiple of 32, typical)
  EOP_FORMAT          1..8 valid bytes in last Data Word (0 = not EOP)
