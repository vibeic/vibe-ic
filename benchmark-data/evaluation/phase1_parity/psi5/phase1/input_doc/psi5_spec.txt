Peripheral Sensor Interface 5 (PSI5) — Automotive Sensor Interface
PSI5 Technical Specification (Peripheral Sensor Interface 5)

ABSTRACT

Peripheral Sensor Interface 5 (PSI5) is a two-wire, current-loop digital
interface for connecting automotive sensors (such as airbag acceleration
sensors, pressure sensors, and other safety and powertrain sensors) to an
electronic control unit (ECU). PSI5 is a point-to-point or bus-capable
interface in which the SAME two wires both supply power to the sensor and
carry the sensor data. The sensor is powered by the ECU over the two-wire
current loop, and the sensor transmits its data back to the ECU by current
modulation: the sensor draws a modulated supply current (a current pulse,
nominally +-26 mA superimposed on the quiescent supply current) and the data
bits are Manchester-coded onto this current. The ECU receives the data by
sensing the current on the loop. PSI5 therefore needs no separate data wire
and no separate clock wire — power, data, and (optionally) synchronization
all share the two-wire current loop.

PSI5 defines two operating modes. In synchronous mode the ECU sends a sync
pulse — a voltage pulse on the supply — that triggers the sensor to transmit
in defined time slots (time-division multiplexing); multiple sensors on a
parallel bus each respond in their own time slot relative to the sync pulse.
In asynchronous mode the sensor transmits autonomously without an ECU sync
pulse. PSI5 supports point-to-point, parallel-bus (several sensors sharing
one two-wire current loop in different time slots), and daisy-chain
(universal timing) topologies.

The PSI5 telegram (data frame) consists of a start condition (start bits),
Manchester-coded data bits, optional region/status bits, and an error-check
field that is either a 2-bit or 3-bit CRC or a parity bit, depending on the
configured data word length. PSI5 supports bit rates of 125 kbps and
189 kbps. A point-to-point variant, PSI5-P, is also defined.

This document specifies the PSI5 physical layer (two-wire current loop,
current modulation, Manchester coding), the synchronous and asynchronous
operating modes (sync pulse, time slots), the topologies (point-to-point,
parallel bus, daisy chain / universal timing), the telegram format
(start condition, data bits, CRC/parity), the bit rates, and the automotive
sensor use cases.

1. OVERVIEW

PSI5 (Peripheral Sensor Interface 5) defines how a remote automotive sensor
communicates with an ECU over just two wires. The defining property of PSI5
is that the two wires form a CURRENT LOOP: the ECU is the supply (it powers
the sensor over the loop) and the sensor is the data transmitter. Rather than
switching a voltage on a dedicated data line, the sensor transmits by
modulating the current it draws from the supply — a current-modulation
(current-mode) physical layer. The nominal modulation is a current pulse of
about +-26 mA on top of the sensor's quiescent supply current. The data is
Manchester-coded onto the current pulses so that each bit carries its own
clock edge, which lets the ECU recover bit timing without a separate clock
wire.

Because power and data share the same two-wire current loop, PSI5 sensors
need no extra wiring: the loop delivers energy to the sensor AND returns the
sensor's measurements to the ECU. This makes PSI5 attractive for
safety-critical automotive sensing (airbag crash sensors, satellite
acceleration and pressure sensors) and for powertrain and chassis sensors.

2. PHYSICAL LAYER — TWO-WIRE CURRENT LOOP AND CURRENT MODULATION

2.1 Two-wire current loop

PSI5 uses two wires. The ECU applies a supply voltage across the two wires
and powers the sensor through the resulting current loop. The sensor is
loop-powered: it draws its operating current from the same two wires it uses
to send data. There is no third wire, no separate ground-referenced data
line, and no separate clock line.

2.2 Current modulation (current-mode signaling)

The sensor transmits data to the ECU by current modulation. To send data the
sensor increases (and decreases) the current it draws from the supply,
producing current pulses on the loop. The nominal modulation amplitude is a
current pulse of approximately +-26 mA superimposed on the quiescent supply
current. The ECU detects the data by sensing this modulated loop current
(for example with a sense resistor in the supply path). This current-loop,
current-modulation physical layer is the central distinguishing feature of
PSI5: the data is carried as a current signal on the power wires, NOT as a
voltage on a dedicated single signal wire.

2.3 Manchester coding

The current pulses are Manchester-coded. In Manchester coding each data bit
is represented by a transition in the middle of the bit period, so the bit
clock is embedded in the data. Manchester coding gives PSI5 a self-clocking
current waveform: the ECU recovers the bit timing from the mid-bit
transitions of the Manchester-coded current pulses, so no separate clock wire
is required on the two-wire current loop.

2.4 Bit rates

PSI5 supports bit rates of 125 kbps and 189 kbps. The bit rate is part of the
configuration of the link and determines the duration of each Manchester-coded
bit on the current loop.

3. OPERATING MODES — SYNCHRONOUS AND ASYNCHRONOUS

3.1 Synchronous mode (sync pulse + time slots)

In synchronous mode the ECU controls when the sensor transmits. The ECU sends
a SYNC PULSE — a voltage pulse on the two-wire supply — and this sync pulse
triggers the sensor(s) to transmit. The sensor transmits its telegram in a
defined TIME SLOT relative to the sync pulse. When several sensors share one
two-wire current loop (a parallel bus), each sensor is assigned its own time
slot, so the sensors transmit in a time-division-multiplexed fashion: sensor
A in slot 1, sensor B in slot 2, and so on, all triggered by the same ECU
sync pulse. Synchronous mode therefore lets the ECU control the timing,
synchronize the sensors, and read multiple sensors over the shared current
loop without collisions.

3.2 Asynchronous mode

In asynchronous mode the sensor transmits autonomously: it sends its
telegrams on its own internal timing, without waiting for an ECU sync pulse.
Asynchronous mode is typically used for a single point-to-point sensor where
no time-slot coordination is needed.

4. TOPOLOGIES

PSI5 supports the following topologies on the two-wire current loop:

4.1 Point-to-point
One sensor connected to the ECU over a dedicated two-wire current loop. The
point-to-point variant PSI5-P is defined for this case.

4.2 Parallel bus
Several sensors share one two-wire current loop. In synchronous mode each
sensor transmits in its own time slot following the ECU sync pulse, so the
sensors are read by time-division multiplexing on the shared loop.

4.3 Daisy-chain (universal timing)
Sensors are connected in a daisy chain. PSI5 defines a universal timing model
for the daisy-chain topology so that the time slots and synchronization are
handled consistently along the chain.

5. TELEGRAM (DATA FRAME) FORMAT

A PSI5 telegram is the data frame the sensor sends to the ECU. The telegram
consists of:

  - Start condition: start bits that mark the beginning of the telegram and
    let the ECU detect the start of a Manchester-coded data word.
  - Data bits: the Manchester-coded sensor data bits (the measurement word).
    The data word length is configurable.
  - Region / status bits: optional bits that may carry region/range or status
    information depending on the configured telegram format.
  - Error check: an error-detection field that is either a 2-bit CRC, a 3-bit
    CRC, or a parity bit, depending on the configured data word length. Short
    data words use a parity bit or a 2-bit CRC; longer data words use a 3-bit
    CRC.

The telegram is transmitted as Manchester-coded current pulses on the
two-wire current loop, beginning with the start condition and ending with the
CRC or parity field.

6. ERROR HANDLING

PSI5 protects each telegram with a CRC (2-bit or 3-bit) or a parity bit so the
ECU can detect corrupted telegrams. A telegram that fails its CRC/parity
check is discarded by the ECU. Loss of the sync pulse, missing telegrams in a
time slot, or out-of-range current are additional error conditions the ECU
monitors.

7. AUTOMOTIVE SENSOR USE CASES

PSI5 is used for automotive safety and powertrain sensors that must be
loop-powered over two wires and report digital data back to the ECU:

  - Airbag / restraint crash sensors (satellite acceleration sensors)
  - Pressure sensors (e.g. side-impact pressure sensors)
  - Acceleration sensors
  - Other safety, chassis, and powertrain sensors

The two-wire current loop, current modulation, Manchester coding, and
sync-pulse-triggered time slots together make PSI5 well suited to robust,
low-wiring-count automotive sensor links.

8. PSI5-P (POINT-TO-POINT VARIANT)

PSI5-P is a point-to-point variant of PSI5 for a single sensor on a dedicated
two-wire current loop. It uses the same two-wire current-loop, current-
modulation, Manchester-coded physical layer.

9. SUMMARY OF KEY PROPERTIES

  - Interface name: Peripheral Sensor Interface 5 (PSI5)
  - Physical layer: two-wire current loop; the same two wires power the sensor
    and carry the data
  - Signaling: current modulation (current-mode); nominal +-26 mA current
    pulses superimposed on the supply current
  - Coding: Manchester coding (self-clocking; embedded bit clock)
  - Direction: sensor -> ECU data; ECU -> sensor power (and sync pulse)
  - Modes: synchronous (ECU sync pulse triggers transmission in time slots)
    and asynchronous (sensor transmits autonomously)
  - Sync: voltage sync pulse on the supply triggers time-slot transmission
  - Time-division: multiple sensors transmit in distinct time slots on a
    parallel bus
  - Topologies: point-to-point, parallel bus, daisy chain (universal timing)
  - Telegram: start condition + Manchester data bits + optional region/status
    bits + 2-bit/3-bit CRC or parity
  - Bit rates: 125 kbps and 189 kbps
  - Variant: PSI5-P (point-to-point)
  - Application: automotive sensors (airbag/acceleration/pressure) to ECU
