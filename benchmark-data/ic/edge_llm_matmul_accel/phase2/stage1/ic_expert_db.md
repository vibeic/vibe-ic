## IC Expert DB — relevant design-class knowledge (advisory)
Proven design-craft for similar designs. Apply the algorithm / interface / latency insight; the deterministic gates still decide PASS.

- **[apb-csr-shift-register]** When a spec says a register "updates on the rising edge of <signal>", model that signal as an actual clock (`always @(posedge signal or negedge presetn)`) rather than sampling it in the main clock domain — the checker drives that signal as a clock edge, so a synchronizer/edge-detector approach would miss updates. Correspondingly, implement glitch-free clock gating by latching the enable on the OPPOSITE (negedge) clock edge before ANDing with the clock (`gated_clk = pclk & enable_latched_on_negedge`), and give misprediction-restore strict priority over the normal LSB shift-in. For the APB CSR wrapper: register-map reads must zero-extend reserved bits, read-only registers must silently ignore writes, and pslverr must assert only on invalid addresses during a qualified (pselx && penable) access with zero wait states (pready held high).
- **[apb-register-peripheral-pwm]** An APB-mapped peripheral must implement the two-phase protocol as a small state bit: SETUP is psel & ~penable, ACCESS is psel & penable, and pready/pslverr/prdata are registered to assert exactly in the ACCESS cycle (pslverr = "address not decoded"); writes commit and reads mux only during ACCESS. When the task is area optimization under a functional-equivalence constraint, restructure only the combinational cloud (e.g. collapse the temperature-to-duty thresholds into one priority ternary, share address-decode terms) while leaving the registered interface timing, reset defaults, and the free-running PWM comparator (fan_pwm_out = counter < duty) bit-identical — changing any cycle of the handshake or a reset value breaks equivalence even if the datapath logic is smaller.
- **[mac-accumulator]** For a multi-stage streaming MAC/accumulator, size the accumulator to exactly 2*DWIDTH + $clog2(N) bits (product width plus carry growth for summing N terms) and gate every pipeline register on a valid signal that has been delayed to match its own stage, so counting, accumulation, and valid_out all track the true datapath latency (first result at N+1 cycles). The critical trap: gapped valid_i must freeze all stages (hold state, advance nothing), and at the window boundary the accumulator must restart by loading the in-flight product rather than zeroing — otherwise the first sample of the next window is dropped and back-to-back windows lose one term.
- **[apb-mmio-register-file]** For an APB/MMIO register-file slave, split the address space so low CSR addresses (0x0-0x5 here) decode to named registers and any address outside that reserved band falls through to the backing memory/SRAM rather than raising an error — only genuinely unmapped writes assert pslverr. Reads must be registered exactly like the spec's 2-cycle no-wait-state contract (pready held high, prdata updated in the same access), and a read-only computed/result address (0x5) is served combinationally from the ALU output, never from a writable register. Do not blanket-error every address above the CSR range, since the same paddr bus is deliberately overloaded for both CSR and memory access.
- **[apb-mmio-register-file-peripheral]** For APB (and similar) memory-mapped register-file peripherals, qualify each write strobe with the correct bus phase — write = psel & pwrite gated to a single phase (here ~penable, the SETUP edge) so the register updates exactly once per transaction rather than every cycle penable is held — and drive prdata only during a read (read_enable) so it reads 0 when idle. A subtle but critical gate-exception trap: when adding a global power-down/soft-disable that masks normal register writes and interrupts, the control register that owns the disable bit (and any interrupt state) must itself stay ungated, otherwise the block latches off with no software path to power back up. Bidirectional inout pins need per-bit tri-state (dir ? dout : 1'bz) with the pin read back through a 2-FF synchronizer before edge/level interrupt logic, and read data should pass through one register stage to honor the stated single-cycle read latency.
