# spm — SOURCE_MANIFEST (REUSED-IP vs GENERATED)

The `spm` design itself (`chip_top`, the shift-and-add multiplier RTL under
`phase2/stage1/rtl/`) is GENERATED by this flow from the Phase-1 documents. It is
not vendored and is not covered by the third-party section below.

This record exists because the published run trees also carry **vendored
third-party PDK cell models**, and Apache-2.0 §4(b)/§4(d) attach to distributing
the *work* — not to publishing a run that used it. The run output may be
withdrawn; while these files are in the tree, the attribution stays with them.
See vibe-ic#1043.
