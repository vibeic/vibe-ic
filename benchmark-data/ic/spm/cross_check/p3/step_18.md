# Step 18 — Spare-cell + ECO-prep insertion (Design-for-ECO)

## What this step is
New flow Step 18 (56-step flow): after detailed placement and BEFORE CTS, a
DISTRIBUTED pool of tied-off spare standard cells (inverter / nand2 / nor2 /
mux2 / aoi / oai / dff) — plus reserved ECO pads when a pad ring exists — is
placed as PHYSICAL `dont_touch` / `keep` instances. This gives the die a
metal-only-ECO budget: a late functional fix can be wired from existing spares
instead of re-spinning base layers. Because spares look exactly like dead
logic, every optimizer (yosys `opt_clean`, OpenROAD `remove_buffers` /
`repair_design` / `repair_timing` / detailed-placement legalization / metal
fill) would strip them unless protected — so each spare is inserted AFTER abc
and marked `dont_touch` + `keep` so no pass can reach it.
