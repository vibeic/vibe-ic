# L6 — Calibration / Lab Procedures

## 適用性 — N/A

- 無 trimming
- 無 OTP-based calibration
- 無 lab measurement procedure
- 無 analog bias adjustment
- 無溫度補償

→ Plugin 不需產生 calibration controller、OTP interface、analog trim DAC 等。
