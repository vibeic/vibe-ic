# Preserve native handoffs and complete expert verification fallbacks

This contribution captures eight general recovery groups as ten records: seven Bucket A program augmentations and three Bucket B judgment lessons. Each lesson explains why deterministic handling is insufficient. Routing uses the existing owning programs and skills.

- **Autonomous IC-expert adjudication (A + B):** Source questions go to an independent IC expert who considers the entire visible hardware contract, preserves discrepancies and justifies a defensible interpretation. Existing hash-bound review correction, fresh review and proof obligations still determine acceptance. Irreducible ambiguity remains unmeasured.
- **Native MCP command resolution (A):** Keep Magic/Fault on their existing deterministic legacy paths. Other tools keep executable built-in legacy paths and otherwise resolve the command on the selected container's PATH. Explicit operator commands retain their meaning and failure behavior. DFT dependency or tool failures stop before success markers or PASS manifests.
- **Public-port ABI observation (A):** Extend the existing native structural contract to compare source-derived public port width, bounds, orientation, signedness and order. Candidate metadata with unsupported provenance remains unmeasured. Repair preserves the original header and inherited functional and review obligations.
- **Interrupted checkpoint and retained handoff (two A records):** Deliver successful worker results to the checkpoint callback during shutdown. Ordinary resume can reconstruct an unaccepted handoff only from a unique original native owner with unchanged source, route, inputs, image and configuration. Retained evidence grants no automatic acceptance.
- **Ordered review correction (A):** Repeated canonical correction flags apply the existing immutable transitions under one coordinator lock, then invoke ordinary resume once. A refused request stops before resume; single-request compatibility remains supported.
- **Reference-model producer advisory (A):** An unfilled reference hook exposes its existing persistent model path and testbench-gen skill. The advisory adds no completion coordinator, model-author record or admission chain. Ordinary native verification on unchanged RTL and fresh independent review remain required.
- **Temporal contract judgment (B):** Derive drive, capture and settled observation phases from the whole visible contract before writing a timing challenge. Preserve unresolved alternatives without applying a universal cycle shift.
- **Reference-model judgment (B):** Derive independent expectations from visible requirements, including width, overflow, flags, reset, deassertion and selection semantics. Require genuine non-skipped comparisons and substantive wrong-behavior controls; expected values cannot come from the DUT or hidden references.
