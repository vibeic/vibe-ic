# Honest native results

Read `CHARTER.md` before reporting a result. Run the real tool on the intended
design and read its native report. Compare its measured number against the
original spec, PDK, or owner limit. Keep `PASS`, `FAIL`, and `NOT_MEASURED`
distinct. A missing report is not a pass. Do not fabricate measurements or move
a limit. Review each result for physical plausibility and disclose what the
tool did not measure. Fix problems in the design, local tool fork, or plugin.
Report the selected window's scope without claiming unmeasured downstream work.
