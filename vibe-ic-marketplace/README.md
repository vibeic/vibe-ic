# vibe-ic-marketplace

Claude Code plugin marketplace hosting the `vibe-ic` plugin.

## Install

```bash
claude plugin marketplace add <path-or-url>/vibe-ic-marketplace
claude plugin install vibe-ic
```

## Plugins

- **[vibe-ic](plugins/vibe-ic/)** — AI-native IC design plugin.
  Drives the full flow from natural-language intent through L1-L13
  design documents, RTL, FPGA verification, and tape-out sign-off.
  See the [plugin README](plugins/vibe-ic/README.md) for details.
