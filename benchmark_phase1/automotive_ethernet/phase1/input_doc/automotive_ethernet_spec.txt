AUTOMOTIVE ETHERNET — SINGLE-TWISTED-PAIR ETHERNET PHY SPECIFICATION
100BASE-T1 (IEEE 802.3bw) / 1000BASE-T1 (IEEE 802.3bp) / 10BASE-T1S (IEEE 802.3cg)
================================================================================

DOCUMENT TITLE
    Automotive Ethernet Physical Layer Specification — Single Unshielded
    Twisted-Pair (UTP, one pair) Ethernet PHY: 100BASE-T1 (IEEE 802.3bw-2015,
    formerly OPEN Alliance BroadR-Reach), 1000BASE-T1 (IEEE 802.3bp-2016), and
    10BASE-T1S / 10BASE-T1L (IEEE 802.3cg-2019). PMA / PCS / PMD layering,
    PAM3 line modulation, simultaneous-bidirectional full-duplex via echo
    cancellation, PHY-level master/slave timing, link training, the 10BASE-T1S
    multidrop Physical Layer Collision Avoidance (PLCA) Reconciliation Sublayer,
    and Energy Efficient Ethernet (EEE) Low-Power Idle (LPI).

VERSION / STANDARDS
    IEEE Std 802.3bw-2015  — 100BASE-T1 (100 Mb/s over one pair). Derived from
                             the Broadcom / OPEN Alliance BroadR-Reach PHY.
    IEEE Std 802.3bp-2016  — 1000BASE-T1 (1 Gb/s over one pair).
    IEEE Std 802.3cg-2019  — 10BASE-T1S (short-reach, multidrop) and
                             10BASE-T1L (long-reach, point-to-point).
    These amendments to IEEE Std 802.3 PRESERVE the IEEE 802.3 Clause-4
    Ethernet MAC frame format. Maintained by the IEEE 802.3 Working Group of
    the IEEE LAN/MAN Standards Committee (LMSC). Driven into the automotive
    industry by the OPEN (One-Pair Ether-Net) Alliance SIG.
    Copyright (c) IEEE.

ABSTRACT
    Automotive Ethernet carries IEEE 802.3 Ethernet over a SINGLE unshielded
    twisted pair (UTP, ONE balanced pair) instead of the four pairs (or 8b10b
    / multi-pair) of standard enterprise Ethernet. Because only one pair is
    available, full-duplex operation is achieved by SIMULTANEOUS BIDIRECTIONAL
    transmission on that one pair with ECHO CANCELLATION: each PHY subtracts
    its own transmitted signal (the near-end echo) from the composite signal
    on the wire to recover the remote signal. One PHY is configured as the
    timing MASTER and the other as the timing SLAVE (PHY-level master/slave
    clocking), so the link is loop-timed.

    100BASE-T1 (IEEE 802.3bw, BroadR-Reach) runs 100 Mb/s using PAM3 (3-level
    pulse-amplitude modulation: -1, 0, +1) at 66.67 MBd, with a 4B3B + 3B2T
    PCS mapping and a scrambler. 1000BASE-T1 (IEEE 802.3bp) runs 1 Gb/s using
    PAM3 at 750 MBd. 10BASE-T1S (IEEE 802.3cg) is a 10 Mb/s SHORT-REACH
    MULTIDROP variant in which several PHYs share one segment and use PLCA
    (Physical Layer Collision Avoidance) implemented as a Reconciliation
    Sublayer to arbitrate access deterministically; 10BASE-T1L is the 10 Mb/s
    LONG-REACH (up to 1000 m) point-to-point process-automation variant.

    Each PHY is layered MAC -> Reconciliation Sublayer (RS, optionally PLCA RS
    for 10BASE-T1S) -> PCS -> PMA -> PMD over the single twisted pair. SNR and
    MSE (mean-squared error) are the principal link-quality metrics. Energy
    Efficient Ethernet (EEE) Low-Power Idle (LPI) reduces power when idle.
    Automotive EMC (electromagnetic compatibility / emissions / immunity) is a
    first-class design constraint. AVB / TSN (Audio Video Bridging / Time-
    Sensitive Networking) and the OPEN Alliance test specifications layer on
    top of the PHY.

================================================================================
1. SCOPE AND MOTIVATION
================================================================================
Standard enterprise Ethernet (10/100/1000BASE-T over Cat-5/Cat-6) uses FOUR
twisted pairs (or, at 100BASE-TX, two pairs with multi-level MLT-3, and at
1000BASE-T, all four pairs bidirectionally). Optical and backplane Ethernet
use 8b10b or 64b/66b line codes over multiple lanes. None of these fit the
automotive harness, where weight, cost, and connector count must be minimised.

Automotive Ethernet therefore defines a family of PHYs that run full Ethernet
over ONE single unshielded twisted pair (one balanced pair, UTP). The single
pair carries traffic in BOTH directions AT THE SAME TIME (simultaneous
bidirectional / full-duplex), separated by echo cancellation. This is the
defining structural property of the T1 (one-pair) family and the reason the
suffix is "T1" (Twisted-pair, 1 pair) rather than "T" (Twisted-pair, 4 pair).

Use cases: in-vehicle networking (ADAS cameras, radar/lidar, infotainment,
zonal architectures, backbone), and — for 10BASE-T1L — industrial process
automation field instruments over long single-pair runs.

================================================================================
2. PHY VARIANTS
================================================================================

2.1 100BASE-T1 (IEEE 802.3bw-2015; formerly OPEN Alliance BroadR-Reach)
    Data rate ........... 100 Mb/s
    Pairs ............... ONE single unshielded twisted pair
    Direction ........... simultaneous bidirectional (full-duplex) on the one
                          pair, separated by ECHO CANCELLATION
    Line modulation ..... PAM3 (3-level: -1, 0, +1; ternary)
    Symbol/baud rate .... 66.67 MBd (66 2/3 MBd)
    PCS coding .......... 4B3B then 3B2T mapping with a side-stream scrambler
                          (maps 4 data bits to 3 ternary symbols)
    Reach ............... up to ~15 m (automotive in-vehicle link segment)
    Timing .............. PHY-level master/slave (one end is the timing master)
    Origin .............. Broadcom BroadR-Reach, standardised by OPEN Alliance,
                          then adopted into IEEE as 100BASE-T1.

2.2 1000BASE-T1 (IEEE 802.3bp-2016)
    Data rate ........... 1 Gb/s (1000 Mb/s)
    Pairs ............... ONE single unshielded (or shielded) twisted pair
    Direction ........... simultaneous bidirectional (full-duplex) with
                          ECHO CANCELLATION
    Line modulation ..... PAM3 (3-level)
    Symbol/baud rate .... 750 MBd
    PCS coding .......... 80B/81B scrambled, RS-FEC (Reed-Solomon) optional in
                          some profiles; ternary PAM3 mapping
    Reach ............... up to ~15 m (Type A) / ~40 m (Type B) automotive
    Timing .............. PHY-level master/slave

2.3 10BASE-T1S (IEEE 802.3cg-2019) — SHORT REACH, MULTIDROP
    Data rate ........... 10 Mb/s
    Pairs ............... ONE single twisted pair
    Topology ............ point-to-point OR MULTIDROP (mixing segment: several
                          PHYs share one short bus segment, up to ~25 m, 8+
                          nodes)
    Direction ........... half-duplex on the shared multidrop segment;
                          full-duplex on a point-to-point link
    Line modulation ..... PAM3-class differential Manchester / DME for the
                          short-reach signalling (4B/5B-style)
    Access control ...... PLCA — Physical Layer Collision Avoidance,
                          implemented as a Reconciliation Sublayer (RS) above
                          the MII that grants each node a deterministic
                          transmit opportunity (TO) in a round-robin cycle,
                          eliminating CSMA/CD collisions on the multidrop bus
    Timing .............. PHY-level master/slave; PLCA coordinator node id 0

2.4 10BASE-T1L (IEEE 802.3cg-2019) — LONG REACH, POINT-TO-POINT
    Data rate ........... 10 Mb/s
    Pairs ............... ONE single twisted pair
    Reach ............... up to 1000 m (process-automation field instruments)
    Direction ........... full-duplex, point-to-point
    Line modulation ..... PAM3
    Timing .............. PHY-level master/slave

================================================================================
3. LAYERED PHY ARCHITECTURE (MAC / RS / PCS / PMA / PMD)
================================================================================
Every automotive-Ethernet PHY preserves the IEEE 802.3 layering:

    MAC (IEEE 802.3 Clause 4)
        Ethernet MAC frame format is PRESERVED, byte-for-byte identical to
        all other Ethernet speeds:
        Preamble (7 x 0x55) + SFD (0xD5) + DA (6) + SA (6) + EtherType/Length
        (2) + Payload (46..1500) + Pad + FCS (4-octet CRC-32, poly 0x04C11DB7).
    Reconciliation Sublayer (RS)
        Maps the MAC to the MII/xMII. For 10BASE-T1S multidrop the PLCA RS
        sits between the MAC's RS and the MII and arbitrates transmit
        opportunities (PLCA = Physical Layer Collision Avoidance).
    PCS (Physical Coding Sublayer)
        100BASE-T1: 4B3B + 3B2T mapping + scrambler.
        1000BASE-T1: 80B/81B scrambled coding.
        Maps the data stream to ternary PAM3 symbols; inserts the
        master/slave scrambler seed.
    PMA (Physical Medium Attachment)
        Symbol timing recovery, ECHO CANCELLATION, adaptive equalisation
        (FFE/DFE), link training, polarity/skew. The PMA hosts the echo
        canceller that subtracts the local transmit signal from the composite
        wire signal so the remote signal can be recovered on the single pair.
    PMD / MDI (Physical Medium Dependent / Medium Dependent Interface)
        The single twisted pair attaches at the MDI (2 wires, one pair). One
        MDI pair, balanced, with automotive EMC filtering / common-mode
        chokes.

================================================================================
4. SIMULTANEOUS BIDIRECTIONAL FULL-DUPLEX & ECHO CANCELLATION
================================================================================
Because only ONE pair is available, both PHYs transmit AT THE SAME TIME on the
same pair. The composite voltage on the wire is (local TX) + (attenuated
remote TX) + (echo/reflections). Each PHY runs an adaptive ECHO CANCELLER that
models its own transmit-to-receive coupling and subtracts the near-end echo,
leaving the remote signal. This is the same hybrid + echo-cancellation
principle used by 1000BASE-T, but over a SINGLE pair rather than four. Echo
cancellation requires loop timing: one PHY (the MASTER) sources the symbol
clock; the other (the SLAVE) recovers and locks to it. This PHY-level
master/slave timing is configured by management or auto-negotiation.

================================================================================
5. PHY-LEVEL MASTER / SLAVE TIMING
================================================================================
One PHY end is the timing MASTER, the other the timing SLAVE:
    MASTER : sources the transmit symbol clock from its local reference;
             its scrambler uses the master seed.
    SLAVE  : recovers the symbol clock from the received signal (loop-timed),
             uses the slave scrambler seed.
The master/slave role is fixed per link by configuration (or resolved by
auto-negotiation / OPEN-Alliance link-up). The roles MUST be opposite at the
two ends or the link will not train. (For 10BASE-T1S multidrop, PLCA node 0
is the coordinator.)

================================================================================
6. LINK TRAINING / STARTUP
================================================================================
PHY startup sequence:
    1. Power-on / reset.
    2. Master/slave roles applied (config or auto-negotiation).
    3. PMA link training: the slave acquires symbol timing from the master;
       the adaptive equaliser (FFE/DFE) and the ECHO CANCELLER converge; SNR
       and MSE (mean-squared error) are driven below the link threshold.
    4. PCS achieves descrambler lock and alignment.
    5. PHY reports link-up (link_status = OK); the MAC begins frame exchange.
SNR and MSE are the principal training/health metrics; a PHY that cannot drive
MSE below threshold within the training timer reports a training failure and
the link stays down.

================================================================================
7. 10BASE-T1S MULTIDROP & PLCA (Physical Layer Collision Avoidance)
================================================================================
10BASE-T1S supports a MULTIDROP "mixing segment": several PHYs (e.g. 8 or more
nodes) share one short single-pair bus. To avoid CSMA/CD collisions, IEEE
802.3cg defines PLCA (Physical Layer Collision Avoidance) as an OPTIONAL
Reconciliation Sublayer (the PLCA RS) inserted between the MAC's RS and the
MII:
    - Each node has a PLCA node ID (0..N). Node 0 is the PLCA COORDINATOR.
    - The coordinator periodically sends a BEACON that starts a PLCA cycle.
    - The cycle grants each node, in node-ID order, a TRANSMIT OPPORTUNITY
      (TO). A node with a frame transmits in its TO; a node with nothing to
      send yields and the TO passes to the next node id.
    - This makes media access DETERMINISTIC and collision-free on the shared
      multidrop segment, which plain CSMA/CD cannot guarantee.
PLCA is transparent to the MAC frame format (still Clause-4 frames). On a
point-to-point 10BASE-T1S link PLCA may be disabled and the link runs
full-duplex.

================================================================================
8. ENERGY EFFICIENT ETHERNET (EEE) / LOW-POWER IDLE (LPI)
================================================================================
Automotive-Ethernet PHYs support EEE (Energy Efficient Ethernet, IEEE 802.3az
family) with Low-Power Idle (LPI): when the MAC has no traffic, the PHY enters
a low-power idle state (analog partially shut down), periodically transmitting
refresh symbols to keep the echo canceller / equaliser coefficients valid, and
wakes on demand with a bounded wake time. EEE/LPI is critical for automotive
power budgets (always-on networks on a vehicle battery).

================================================================================
9. SNR / MSE LINK QUALITY
================================================================================
Link quality is monitored via:
    SNR  : signal-to-noise ratio at the slicer.
    MSE  : mean-squared error of the equaliser/slicer (the residual error
           after echo cancellation + equalisation). MSE below a configured
           threshold is the link-up criterion; rising MSE warns of cable /
           connector / EMC degradation.
These are exposed via PHY management registers (MDIO) for in-system diagnostics
and OPEN-Alliance compliance test (link quality, return loss, EMC).

================================================================================
10. AUTOMOTIVE EMC
================================================================================
Automotive EMC (electromagnetic compatibility) is a first-class requirement:
controlled emissions (the PAM3 ternary signalling + scrambler limit the
spectrum), high immunity (the differential pair + common-mode chokes reject
bulk-current-injection and field coupling), and limited reach to keep coupled
noise bounded. OPEN-Alliance TC publishes the automotive EMC + interoperability
test specifications layered on the IEEE PHY.

================================================================================
11. MANAGEMENT (MDIO) & REGISTERS
================================================================================
The PHY is managed over the IEEE 802.3 MDC/MDIO management bus (Clause 22
basic registers + Clause 45 MMD extensions). Key items:
    BMCR/BMSR basic control/status (Clause 22).
    Master/slave configuration (manual or auto).
    PMA/PCS status: link-up, training state, SNR, MSE.
    PLCA control/status registers (10BASE-T1S): PLCA enable, node ID,
       node count, beacon, transmit-opportunity timer.
    EEE/LPI control.
    Vendor diagnostics: echo-canceller taps, equaliser coefficients,
       temperature.

================================================================================
12. ETHERNET FRAME FORMAT (PRESERVED — IEEE 802.3 CLAUSE 4)
================================================================================
The MAC frame is byte-for-byte identical to all other Ethernet speeds:
    Preamble ............ 7 octets of 0x55
    SFD ................. 1 octet 0xD5
    Destination Address . 6 octets (48-bit MAC)
    Source Address ...... 6 octets (48-bit MAC)
    EtherType/Length .... 2 octets (>=0x0600 EtherType, <=0x05DC Length)
    Payload ............. 46..1500 octets
    Pad ................. to reach the 64-octet minimum frame
    FCS ................. 4 octets, CRC-32, polynomial 0x04C11DB7
Minimum frame 64 octets, maximum 1518 octets (untagged) / 1522 (VLAN-tagged).
Inter-packet gap nominal 96 bit times. The FCS uses the standard IEEE 802.3
CRC-32 (0x04C11DB7, init 0xFFFFFFFF, final XOR 0xFFFFFFFF, LSB-first).

================================================================================
13. ERROR / FAULT CONDITIONS
================================================================================
    - Link training failure: MSE cannot be driven below threshold within the
      training timer; link stays down.
    - Master/slave misconfiguration: both ends master (or both slave) — the
      link never trains.
    - Loss of descrambler lock: PCS de-locks; link down.
    - SNR/MSE degradation above threshold: warns of cable/connector/EMC fault.
    - FCS (CRC-32) mismatch: receive MAC discards the frame.
    - Runt (<64 B) / giant (>1518/1522 B) frame: discarded.
    - PLCA (10BASE-T1S): a node transmitting outside its transmit opportunity
      is a PLCA violation; missing beacon recovers to a free-for-all timeout.

================================================================================
14. TEST / DEBUG / COMPLIANCE
================================================================================
    - PMA test modes / transmitter test patterns for emissions + jitter.
    - SNR / MSE readout via MDIO for in-system link-quality monitoring.
    - PLCA status counters (10BASE-T1S).
    - OPEN-Alliance interoperability + EMC compliance test specifications.
    - Loopback (PMA / PCS) for board bring-up.
    - Master/slave force for channel characterisation.

================================================================================
15. RELATION TO STANDARD ETHERNET — WHAT IS DIFFERENT
================================================================================
Automotive Ethernet keeps the IEEE 802.3 MAC frame, so frames are
interoperable end-to-end with any other Ethernet once both ends are up. What
is ENTIRELY DIFFERENT below the MAC:
    - ONE twisted pair instead of four (T1 vs T).
    - Simultaneous-bidirectional full-duplex on that one pair via ECHO
      CANCELLATION (not separate TX/RX pairs).
    - PAM3 ternary line modulation (not MLT-3 / 8b10b / PAM4).
    - PHY-level master/slave loop timing.
    - 10BASE-T1S multidrop with PLCA (no multidrop in standard BASE-T).
A 100BASE-T1 PHY CANNOT link to a 100BASE-TX (2-pair) or 1000BASE-T (4-pair)
PHY; only the frames are compatible after both ends are independently up.
