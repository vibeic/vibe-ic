DDR4 SDRAM Standard
JEDEC Standard No. 79-4 (JESD79-4)
DDR4 SDRAM Specification

JEDEC Solid State Technology Association

==================================================================
1. SCOPE AND OVERVIEW
==================================================================

This document defines the DDR4 SDRAM (Double Data Rate Fourth-generation
Synchronous Dynamic Random Access Memory) standard, JEDEC Standard
JESD79-4. DDR4 is the mainstream commodity main-memory DRAM generation
that succeeds DDR3 (JESD79-3) and precedes DDR5 (JESD79-5).

A DDR4 SDRAM is a high-speed, clocked, double-data-rate dynamic memory.
Commands and addresses are captured on the rising edge of the
differential clock CK_t/CK_c; data DQ is transferred on both edges of
the differential data strobe DQS_t/DQS_c (double data rate). DDR4
defines a single 64-bit data channel per DIMM (72-bit with ECC). DDR4
devices are offered as x4, x8, and x16 organizations.

DDR4 introduces, relative to DDR3:
  - Bank Groups (a new addressing tier).
  - Gear-down mode (1/2-rate command/address capture).
  - Data Bus Inversion (DBI).
  - Internal VrefDQ generation and VrefDQ training (DQ reference moved
    on-die).
  - Write Cyclic Redundancy Check (write CRC) on the data bus.
  - Command/Address parity (CA parity, the C/A parity feature).
  - Reduced supply voltage: VDD = VDDQ = 1.2 V (DDR3 used 1.5 V).

DDR4 retains the burst-oriented, bank-organized, mode-register-driven
SDRAM command model of prior DDR generations, with ACTIVATE / READ /
WRITE / PRECHARGE / REFRESH commands and the timing parameters tRCD,
tRP, tRAS, tRC, tRFC, tWR, tWTR, tCCD.

==================================================================
2. SINGLE-CHANNEL ORGANIZATION
==================================================================

DDR4 defines a SINGLE data channel per module. A standard DDR4 UDIMM /
RDIMM presents one 64-bit-wide data path (DQ[63:0]); an ECC module
presents 72 bits (64 data + 8 ECC). This is the defining organizational
difference from DDR5, which splits the module into two independent
32-bit (40-bit ECC) sub-channels. DDR4 has NO sub-channel split: a
single command/address bus drives the full 64-bit data width.

Per-device data widths:
  - x4  : DQ[3:0],  one DQS_t/DQS_c pair per device.
  - x8  : DQ[7:0],  one DQS_t/DQS_c pair, one DM_n/DBI_n.
  - x16 : DQ[15:0], two DQS pairs (lower/upper byte), two DM_n/DBI_n.

==================================================================
3. SUPPLY VOLTAGE
==================================================================

DDR4 operates at:
  VDD  = 1.2 V (core)
  VDDQ = 1.2 V (DQ I/O)
  VPP  = 2.5 V (DRAM activating / wordline pump supply, new in DDR4)
  VREFCA externally supplied; VREFDQ generated INTERNALLY (on-die) and
         set by VrefDQ training (a DDR4 feature — DDR3 used an external
         VREFDQ).

The 1.2 V VDD/VDDQ rail is a primary DDR4 discriminator versus DDR3's
1.5 V rail.

==================================================================
4. BANK GROUPS AND BANK ORGANIZATION
==================================================================

DDR4 introduces BANK GROUPS, a new addressing hierarchy not present in
DDR3. The banks of a DDR4 device are partitioned into bank groups:

  - x4 and x8 devices : 4 bank groups, each with 4 banks = 16 banks.
  - x16 devices       : 2 bank groups, each with 4 banks = 8 banks.

Bank group address pins:
  - BG0, BG1 select the bank group (x4/x8: BG0/BG1; x16: BG0 only).
  - BA0, BA1 select the bank within the bank group.

Bank groups exist so that consecutive accesses to DIFFERENT bank groups
can run back-to-back at the short column-to-column delay tCCD_S (CCD
short), while accesses WITHIN the SAME bank group incur the longer
tCCD_L (CCD long). This bank-group timing split (tCCD_S vs tCCD_L,
tRRD_S vs tRRD_L, tWTR_S vs tWTR_L) is unique to DDR4's bank-group
architecture and lets DDR4 hide internal array recovery time at high
data rates.

==================================================================
5. GEAR-DOWN MODE
==================================================================

DDR4 defines GEAR-DOWN MODE, programmable via Mode Register MR3. In the
default 1/1-rate (full-rate) mode, command/address is sampled on every
rising CK edge. In GEAR-DOWN (1/2-rate) mode, the command/address bus is
sampled on every OTHER rising clock edge, halving the effective CA
capture rate to ease command-bus timing at the highest DDR4 speed bins.
Gear-down requires a defined synchronization (Sync) pulse to align the
controller and DRAM to the same 1/2-rate command phase. Gear-down mode
is a DDR4 feature introduced in JESD79-4.

==================================================================
6. DATA BUS INVERSION (DBI)
==================================================================

DDR4 supports DATA BUS INVERSION (DBI), enabled via Mode Register MR5.
DBI minimizes the number of DQ lines driven LOW within a byte (DBI-dc)
to reduce I/O power and SSO (simultaneous switching output) noise. When
DBI is enabled, the DM_n pin is repurposed as the DBI_n (Data Bus
Inversion) pin per byte: if more than half the DQ bits in a byte would
be 0, the byte is inverted and DBI_n is asserted. DBI applies to reads
(read DBI) and writes (write DBI) independently. DBI and the
Data-Mask (DM) function share the DM_n/DBI_n pin and are mutually
exclusive per direction (DM and write-DBI cannot both be enabled).

==================================================================
7. VREFDQ INTERNAL GENERATION AND TRAINING
==================================================================

DDR4 moves the DQ reference voltage (VREFDQ) ON-DIE. Each DDR4 SDRAM
generates its own VREFDQ internally, programmable over a defined range
in fine steps via Mode Register MR6. The controller runs a VREFDQ
TRAINING sequence (VrefDQ training), entered through MR6, to center the
internal DQ reference within the data eye for each device. The DRAM
provides a VREF training range select (Range 1 / Range 2) and a step
adjust. On-die VREFDQ with controller-directed training is a DDR4
feature; DDR3 used an externally supplied VREFDQ.

==================================================================
8. WRITE CRC (DATA-BUS CRC)
==================================================================

DDR4 defines a WRITE CRC (Cyclic Redundancy Check) on the data bus,
enabled via Mode Register MR2. When write CRC is enabled, each 8-beat
write burst (BL8) carries an 8-bit CRC checksum appended in two extra
data-bus cycles (a CRC frame covering 72 bits per lane group). The DDR4
write-CRC polynomial protects write data integrity at high data rates;
on a detected CRC error the DRAM signals the error via the ALERT_n pin
and the write is not committed, allowing the controller to retry. Write
CRC is a DDR4 data-bus integrity feature.

==================================================================
9. COMMAND/ADDRESS PARITY (CA PARITY)
==================================================================

DDR4 defines COMMAND/ADDRESS PARITY (CA parity, the C/A parity
feature), enabled via Mode Register MR5. A single even-parity bit (PAR
pin) covers the command and address inputs (ACT_n, RAS_n/A16,
CAS_n/A15, WE_n/A14, the address bus, bank, and bank-group pins) for
each command. The DRAM checks parity over the registered command; on a
parity error it blocks execution of the command, logs the error, and
asserts the ALERT_n pin for the programmed CA-parity error window
(persistent error mode), after which normal operation resumes. CA
parity plus the ALERT_n mechanism are DDR4 command-integrity features.

==================================================================
10. BURST LENGTH (BL8 / BC4)
==================================================================

DDR4 transfers data in bursts. The burst length is set in Mode Register
MR0:
  - BL8  : fixed burst length of 8 (eight data beats per access).
  - BC4  : burst chop of 4 (four data beats).
  - BL8/BC4 on-the-fly (OTF) : the A12/BC_n address bit selects BL8 or
    BC4 per READ/WRITE command at runtime.
A BL8 access fills a 64-byte cache line on a 64-bit channel.

==================================================================
11. SPEED BINS
==================================================================

DDR4 speed bins (data rate in MT/s, double the CK frequency):
  DDR4-1600  (CK 800 MHz)
  DDR4-1866
  DDR4-2133
  DDR4-2400
  DDR4-2666
  DDR4-2933
  DDR4-3200  (CK 1600 MHz)

DDR4 is a DLL-based SDRAM: an on-die Delay-Locked Loop aligns the output
DQS/DQ to the input clock CK. Each speed bin defines CL (CAS latency),
tRCD, tRP, and tRAS in the speed-bin tables. The data rate is twice the
CK rate because DQ is transferred on both clock/strobe edges (double
data rate).

==================================================================
12. RDIMM / LRDIMM: RCD AND DATA BUFFER
==================================================================

DDR4 registered modules use the Registering Clock Driver (RCD) to
re-drive and re-clock the command/address bus to the DRAMs, reducing the
controller's command-bus load.

  - RDIMM (Registered DIMM): an RCD registers the command/address/control
    bus; data DQ connects directly to the DRAMs.
  - LRDIMM (Load-Reduced DIMM): an RCD registers command/address AND a
    set of Data Buffers (DB) buffer the DQ/DQS data bus, isolating the
    DRAM loads from the host data channel to allow more ranks at higher
    speed.

The RCD and DB are DDR4 module components defined by JEDEC alongside
JESD79-4 (the DDR4 RCD01 and DB01 standards).

==================================================================
13. MODE REGISTERS (MR0..MR6)
==================================================================

DDR4 defines seven mode registers, programmed by the MRS (Mode Register
Set) command:

  MR0 : Burst Length (BL8/BC4/OTF), Read CAS Latency (CL), Burst Type
        (sequential/interleave), Write Recovery (tWR)/Read-to-Precharge,
        DLL Reset, Test Mode.
  MR1 : DLL Enable, Output Drive Strength (RZQ/6, RZQ/7), Rtt_Nom
        (nominal ODT), Additive Latency (AL), Write Leveling enable,
        TDQS, Qoff.
  MR2 : Write CAS Latency (CWL), Rtt_WR (dynamic ODT for writes), Write
        CRC enable, Auto Self-Refresh (ASR), LP Auto Self-Refresh.
  MR3 : Multi-Purpose Register (MPR) access + MPR page select, Gear-down
        mode, Per-DRAM Addressability (PDA), Write/Read command latency
        for CRC/DM/Gear-down, Fine Granularity Refresh, Temperature
        sensor readout.
  MR4 : CAL (Command Address Latency), Read/Write Preamble (1tCK/2tCK),
        Self-Refresh Abort, Max Power-Down mode, Temperature-controlled
        refresh, Internal VREF monitor, CS-to-CMD/ADDR latency.
  MR5 : CA parity latency / enable, CRC error status / clear, ODT input
        buffer power-down, CA parity persistent error, Data Bus
        Inversion (read DBI / write DBI), Rtt_PARK.
  MR6 : tCCD_L programming, VrefDQ training enable, VrefDQ training
        range (Range 1 / Range 2), VrefDQ training value (step).

==================================================================
14. COMMAND TRUTH TABLE
==================================================================

DDR4 multiplexes the legacy RAS_n / CAS_n / WE_n function pins with high
address bits and adds the ACT_n (Activate) pin:

  Pin       DDR4 dual function
  ACT_n     Activate command flag (LOW = ACTIVATE).
  RAS_n/A16 RAS_n when ACT_n LOW; address A16 when ACT_n HIGH.
  CAS_n/A15 CAS_n when ACT_n LOW; address A15 when ACT_n HIGH.
  WE_n/A14  WE_n  when ACT_n LOW; address A14 when ACT_n HIGH.

Command encoding (CKE, CS_n, ACT_n, RAS_n/A16, CAS_n/A15, WE_n/A14):

  ACTIVATE (ACT)  : ACT_n=L, opens a row in a bank (bank group BG, bank
                    BA, row address). Timing tRCD before column access.
  READ (RD)       : ACT_n=H, RAS_n=H, CAS_n=L, WE_n=H. Column read; CL
                    later, DQ burst on DQS edges.
  WRITE (WR)      : ACT_n=H, RAS_n=H, CAS_n=L, WE_n=L. Column write; CWL
                    later, DQ burst captured on DQS.
  PRECHARGE (PRE) : ACT_n=H, RAS_n=L, CAS_n=H, WE_n=L. Closes a row;
                    tRP before the next ACTIVATE.
  REFRESH (REF)   : ACT_n=H, RAS_n=L, CAS_n=L, WE_n=H, all banks idle;
                    tRFC. Fine Granularity Refresh (1x/2x/4x) selectable.
  MRS             : Mode Register Set (ACT_n=H, RAS_n=L, CAS_n=L, WE_n=L).
  ZQ CALIBRATION  : ZQCL (long) / ZQCS (short) calibrate output driver
                    and ODT against the external RZQ (240 ohm) resistor.
  NOP / DES       : No-operation / Deselect.

Auto-precharge (A10/AP) issues an automatic PRECHARGE after the burst.

==================================================================
15. KEY TIMING PARAMETERS
==================================================================

  tRCD  : ACTIVATE-to-READ/WRITE (RAS-to-CAS) delay.
  tRP   : PRECHARGE period.
  tRAS  : ACTIVATE-to-PRECHARGE (row active time).
  tRC   : tRAS + tRP (ACTIVATE-to-ACTIVATE same bank).
  tRFC  : REFRESH-to-ACTIVATE / REFRESH cycle time.
  tWR   : WRITE recovery time.
  tCCD_S: column-to-column delay, different bank group (CCD short).
  tCCD_L: column-to-column delay, same bank group (CCD long).
  tRRD_S/tRRD_L : ACTIVATE-to-ACTIVATE delay (different / same bank group).
  tWTR_S/tWTR_L : WRITE-to-READ turnaround (different / same bank group).
  tFAW  : four-activate window.
  tREFI : average refresh interval (7.8 us at <=85 C, 3.9 us above).
  CL/CWL: read / write CAS latency (from the speed-bin tables).

==================================================================
16. PIN / SIGNAL LIST
==================================================================

  CK_t, CK_c        : differential input clock.
  CKE               : clock enable (power-down / self-refresh control).
  CS_n              : chip select (per rank).
  ACT_n             : activate command flag.
  RAS_n/A16, CAS_n/A15, WE_n/A14 : multiplexed command / high address.
  A[13:0]           : address bus (row / column).
  A10/AP            : auto-precharge / precharge-all.
  A12/BC_n          : burst chop on-the-fly select.
  BG0, BG1          : bank group address.
  BA0, BA1          : bank address.
  DQ[3:0] / [7:0] / [15:0] : bidirectional data (x4/x8/x16).
  DQS_t, DQS_c      : differential bidirectional data strobe (per byte).
  DM_n / DBI_n      : data mask / data bus inversion (shared pin, x8/x16).
  TDQS_t/TDQS_c     : termination data strobe (x8, when enabled).
  PAR               : command / address parity input.
  ALERT_n           : CA-parity error / CRC error / connectivity alert.
  ODT               : on-die termination control.
  RESET_n           : asynchronous reset.
  ZQ                : external reference (RZQ 240 ohm) for calibration.
  VDD=1.2V, VDDQ=1.2V, VPP=2.5V, VREFCA, VSS, VSSQ : supplies.

==================================================================
17. ON-DIE TERMINATION (ODT)
==================================================================

DDR4 supports On-Die Termination with three values:
  - Rtt_Nom  : nominal ODT, controlled by the ODT pin (MR1).
  - Rtt_WR   : dynamic ODT during writes (MR2).
  - Rtt_PARK : parked ODT applied when ODT is deasserted (MR5, new in
               DDR4).
ODT values are expressed as fractions of RZQ (e.g. RZQ/4 = 60 ohm).

==================================================================
18. REFRESH AND LOW POWER
==================================================================

DDR4 supports:
  - All-bank and per-bank REFRESH.
  - Fine Granularity Refresh (1x / 2x / 4x) trading tRFC for tREFI.
  - Self-Refresh (CKE LOW + command), with Auto Self-Refresh (ASR) and
    temperature-controlled / low-power self-refresh ranges.
  - Precharge power-down and active power-down (CKE LOW).
  - Maximum Power Saving Mode (MR4) for deep idle.

==================================================================
19. DISTINCTION FROM SIBLING MEMORY STANDARDS
==================================================================

DDR4 (this document, JESD79-4) is distinguished from:

  - DDR3 (JESD79-3): DDR3 runs at 1.5 V, has NO bank groups (8 banks via
    BA0..BA2 only), NO gear-down mode, NO write CRC, NO CA parity, NO
    on-die VREFDQ, and uses an external VREFDQ. DDR4 adds all of these.

  - The next DRAM generation (the JESD79 fifth-generation standard):
    that generation splits the module into two narrower independent
    sub-channels and adds receiver equalization, on-die error correction,
    and an on-module power-management device with an SPD hub at a lower
    rail. DDR4 instead presents a SINGLE 64-bit channel at 1.2 V with one
    command/address bus driving the full data width. This document does
    NOT define a sub-channel split, receiver equalization, on-die error
    correction, or an on-module power-management device.

  - Low-power mobile DRAM (the JESD209 mobile standard): a mobile DRAM
    family with a dedicated full-speed write strobe clock separate from
    CK. DDR4 has no such separate write clock.

  - Stacked 3D DRAM (the high-bandwidth stacked-DRAM standard): a
    wide-interface through-silicon-via stacked 3D DRAM. DDR4 is a planar,
    single-channel, 64-bit commodity DRAM with no through-silicon vias.

DDR4 is identified by: JESD79-4, 1.2 V VDD/VDDQ, bank groups, gear-down
mode, write CRC, CA parity, Data Bus Inversion, and on-die VrefDQ
training, WITHOUT the next generation's decision-feedback equalization /
two-sub-channel / on-die-error-correction / on-module-power-management
feature set.
